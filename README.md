# Surani Altitude Travel Website

A free, responsive travel company website built with HTML, CSS and JavaScript.

## Files

- `index.html` — main website
- `css/style.css` — design and responsive styles
- `js/script.js` — trip data, itinerary modal, WhatsApp interactions

## Run locally

1. Open the folder in VS Code.
2. Open `index.html` in a browser.
3. For easier development, install the VS Code "Live Server" extension and choose **Open with Live Server**.

## Before publishing

### 1. Google Booking Form
In `index.html`, find:

`https://docs.google.com/forms/`

Replace it with your actual published Google Form URL.

The website already supports:
- trip selection
- direct WhatsApp enquiry
- phone/email/Instagram contact

### 2. Photos and logo
The first version uses remote Unsplash images as temporary placeholders.

For the final branded version, replace those URLs in `js/script.js` and `css/style.css` with your own travel photos. Add your logo to the project if you have one.

### 3. Important package checks
Before publishing paid advertisements, confirm:
- Trip 5 3AC price
- Saputara final duration (your supplied itinerary has Day 1–Day 4 although the duration says 3D/2N)
- Any Trip 3/4/5/6 inclusions and exclusions you want shown publicly
- Exact departure dates, if you want individual dates displayed

## GitHub Pages

Create a GitHub repository, upload this folder's contents, then enable:

Settings → Pages → Deploy from branch → `main` → `/ (root)`

Your free website will then be available at your GitHub Pages URL.
